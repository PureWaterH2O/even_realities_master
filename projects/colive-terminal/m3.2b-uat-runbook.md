## What this rung adds (read this first)
Two composer affordances, both **pure typing aids that produce clean text Claude acts on** — the desk **never reads file
contents** and **never runs a shell** (it only enumerates *filenames* via `git ls-files`):
- **`@`-file autocomplete (mid-line):** type `@` anywhere in a line → a fuzzy file-path menu opens; **↑/↓** move, **Tab/
  Enter** insert the chosen repo-relative `@path` at the cursor, **Esc** dismisses (keeping your line). On submit, the
  `@path` is sent **verbatim** — Claude reads the file with its **Read** tool (in Core).
- **`!`bash (whole-line):** a line beginning with `!` is a shell command. It's transformed into a "run this and show
  output" instruction and POSTed — Claude runs it with its **Bash** tool (in Core), **gated by the M1 permission flow**,
  and it renders as a normal `Bash(...)` tool call in the M3.1 transcript. **One command per submit;** a lone `!` is a
  no-op. (Honest divergence from native `!`: this is a *model turn*, not a silent local peek — accepted tradeoff,
  spec §3.3.)

These compose with the existing M3.2A menus: the `/` menu (whole-buffer leading `/`) and the `@` menu (mid-line token)
are **mutually exclusive by construction** and never both open; `!` opens no menu.

## Keybinding map (the new bits)
| Key | macOS-laptop | Action |
|---|---|---|
| **`@` …** | same | Open the `@`-file menu on the token under the cursor; filters as you type |
| **↑ / ↓** (menu open) | ↑ / ↓ | Move the `@`-menu highlight |
| **Tab** (menu open) | Tab | Insert the highlighted `@path` (replaces the `@query` token, adds a trailing space) |
| **Enter** (`@` menu open) | Return | Insert the highlighted `@path` (the `@` menu accepts on Enter; the `/` menu does **not** — Enter submits it) |
| **Esc** (`@` menu open) | esc | Dismiss the `@` menu **and keep the typed line** (does not clear it) |
| **`!cmd`** then **Enter** | same | Run `cmd` via Claude's Bash tool (permission-gated); the command echoes into the transcript |
