## ⚠️ Decisions needed from the planner (judgment calls)

1. **Prompt glyph:** plan Task 6 said change `>` → `❯` (U+2771). The **actual native glyph is `›` (U+203A)** — thinner. Use `›`. *(affects D-002, D-003)*
2. **Collapsed thinking (D-012):** native leaves **no** inline stub (thinking folds away; only a `✱ Worked for Ns` footer remains). Ours shows `💭 thinking (N lines) — Ctrl-O`. Match native (hide it) or keep our discoverable stub? Our stub is arguably *better* UX — recommend keeping but restyling.
3. **Scrollback (D-022):** native has **no in-app scroll indicator** (it relies on terminal-native scrollback). Ours runs a managed pinned viewport + `rows N–M of Z` indicator — load-bearing for the desk's fixed-region redraw (UAT A1). Matching native = drop the viewport, a big regression risk. **Recommend KEEP ours** and mark D-022 won't-fix.
4. **Deep dashboards (D-023…D-027):** native `/cost`, `/usage`, `/config`, `/memory`, `/effort` are rich full-screen views. M3.5's bar is "indistinguishable **at a glance**" for the daily-driver chrome, not byte-parity on stats dashboards. **Recommend descope** `/cost`·`/usage`·`/config`·`/memory` for M3.5; consider only `/effort` if effort becomes a desk control.

## Tool headers — plan Task 8 · `src/desk/render/rows.ts` (`case 'tool'`)

**D-004 — Tool bullet glyph** · **minor** · all tool scenarios · fix: `rows.ts` (`⏺` → `●`)
- Native: `●` (filled circle; green on success, presumably red on error). Ours: `⏺`.

**D-005 — Tool header summary** · **medium** · scenarios 05,06,07,08,18 · fix: `rows.ts` `case 'tool'`
- Native: natural-language per-tool summaries — Read → `Read 1 file`, Bash → `Listed 1 directory`, Write → `Write(/tmp/m35-test.txt)`, Agent → `Agent(<description>)`. Ours: uniform `Name(arg)` (e.g. `Edit(src/greet.ts)`).

**D-006 — Result sub-line + expand affordance** · **medium** · scenarios 05,06,07,18 · fix: `rows.ts`
- Native: a `⌐`-prefixed result line under the header (`⌐ Wrote 1 lines to <path>`, `⌐ Done (0 tool uses · 11.3k tokens · 1s)`) and a `(ctrl+o to expand)` hint. Ours: header only; detail lives behind Ctrl-O verbose with no inline hint.

**D-007 — Turn timing footer** · **medium** · scenarios 04,05,06,07,18 · fix: `app.tsx` / `rows.ts` (per-turn footer from duration)
- Native: each completed turn ends with `✱ <verb> for Ns` — a randomized playful verb (observed: Brewed, Cogitated, Crunched, Baked, Worked, Churned). Ours: nothing.

**D-008 — Active/busy spinner line** · **medium** · scenarios 10,14,17 · fix: `app.tsx` (in-transcript activity line) — overlaps T15
- Native: while working, an inline `✱ <verb>… (Ns · ↑ N tokens · thinking with high effort)` (also seen as `· Summarizing the file… (16s · ↑ 867 tokens)`). Ours: only the `[busy · …]` status line; no inline spinner/elapsed/token line.
