# M3.5 Aesthetic Pass — UAT Runbook

> **Goal:** confirm the desk client is "indistinguishable at a glance" from native Claude Code
> running in the same VS Code integrated terminal.
>
> **Setup:** VS Code with three terminal tabs + native Claude in a fourth.
>
> **Tab 1 — Hub server:**
> ```
> cd ~/Documents/random_claude_stuff/even_realities/colive-terminal && npx tsx src/index.ts serve
> ```
>
> **Tab 2 — Our desk client** (after server is running):
> ```
> cd ~/Documents/random_claude_stuff/even_realities/colive-terminal && npx tsx src/index.ts desk
> ```
>
> **Tab 3 — Native Claude Code** (the comparison target):
> ```
> claude
> ```
>
> Put Tab 2 (our desk) and Tab 3 (native) side by side. For each scenario: do the same
> thing in both panes, compare visually. Mark PASS if they look the same at a glance,
> FAIL + note if they don't.
>
> **Accepted divergences (not failures):**
> - Our scrollback has a `rows N–M of Z (pinned ▼)` indicator; native uses terminal-native scroll (D-022 won't-fix)
> - Status line lacks `ctx: N%`, `5h: N%`, `7d: N%` — we don't have that data
> - `/cost`, `/usage`, `/config`, `/memory`, `/effort` views — descoped from M3.5
> - Bash tool shows command text, not native's semantic summary ("Listed 1 directory")
> - Thinking stub shows `· thinking (N lines) — ctrl+o to expand` — intentionally kept (native hides it)
