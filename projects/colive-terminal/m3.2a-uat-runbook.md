## What changed since M3.1 (read this first)
M3.1's input was a single-line buffer and the **arrow keys scrolled the transcript** (alt-screen mapped the wheel to ↑/↓).
M3.2A makes the input a real **composer** and **reassigns the arrows**:
- **↑ / ↓ now drive the input** (command history at the edges; cursor between draft lines) — they no longer scroll.
- **Transcript scrolling moves to the mouse wheel** (real SGR mouse reporting is now enabled) **and PageUp/PageDown**.
- **Cost (expected):** with mouse reporting on, selecting/copying transcript text now needs **Option-drag (macOS)** /
  Shift-drag — the vim/less/tmux convention. (If a terminal won't forward SGR mouse, the wheel won't scroll; PageUp/
  PageDown still do — see A6.)

## Keybinding map (as built) — with macOS-laptop equivalents
> On a Mac laptop there are no dedicated PageUp/PageDown/Home/End keys — they are `Fn`+arrow combos.

| Key | macOS-laptop | Action |
|---|---|---|
| **Enter** | Return | Submit the prompt |
| **Ctrl-J** / **`\`+Enter** | same | Insert a newline (keep composing). (Shift+Enter too **if** your terminal sends it) |
| **↑ / ↓** | ↑ / ↓ | History prev/next **when the cursor is on the top/bottom line**; otherwise **move the cursor** between draft lines |
| **← / →** | ← / → | Move cursor by character |
| **Option+← / Option+→** | ⌥+← / ⌥+→ | Move cursor by word |
| **Ctrl-A / Ctrl-E** | ⌃A / ⌃E | Cursor to line start / line end (the reliable line-nav keys) |
| **End** | **Fn+→** | Line end **while editing**; **re-pin the transcript to live when the input is empty** |
| **Backspace** | Delete | Delete the char before the cursor |
| **Ctrl-W** | ⌃W (or ⌥+Delete) | Delete the word before the cursor |
| **Mouse wheel** | two-finger trackpad scroll | Scroll the transcript (real mouse reporting) |
| **PageUp / PageDown** | **Fn+↑ / Fn+↓** | Page the transcript up / down |
| **`/` …** | same | Open the slash menu; ↑/↓ navigate, **Tab** completes, **Enter** runs, **Esc** closes |
| **`/select` · `/scroll`** | same | Mouse-mode toggle: `/select` turns mouse reporting **off** (native drag-select + Cmd-C; wheel off) · `/scroll` turns it back **on** (wheel scroll; default). Status line shows `select-mode` while off. |
| **Ctrl-O** | ⌃O | Toggle global verbose (unchanged from M3.1) |
| **Esc** | esc | Close the slash menu if open; else interrupt the running turn (M1) |
| **Ctrl-C** | ⌃C | Quit |
