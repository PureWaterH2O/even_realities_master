## Keybindings (as built)
- **PageUp / PageDown** — scroll the transcript viewport one page.
- **End** — jump to the bottom and re-pin to live (streaming auto-pins to bottom; any scroll-up unpins).
- **Ctrl-O** — toggle global verbose (default OFF): ON shows every tool block's full input/output and expands
  closed thinking; OFF shows tool one-liners + a thinking stub. Live-streaming thinking shows regardless.
- **Esc** — interrupt (unchanged from M1). **Enter** — submit. **Ctrl-C** — quit.
- (Arrow keys are intentionally inert in M3.1 — reserved for the M3.2 input editor/history. Mouse-wheel scroll is
  not supported — accepted terminal ceiling.)

## Preconditions
- M3.1 branch checked out; `npm test` + `npm run typecheck` green (controller-verified from a clean tree — precondition only).
- **Launch (bin not installed yet):** from `colive-terminal/` run `npm run dev -- serve` in one terminal and
  `npm run dev -- desk` in the VS Code integrated terminal. **Make the desk terminal tall** (more rows = more
  viewport). If you relaunch desk, the previous run's lines stay in the host scrollback — that's the host
  terminal's own buffer, not the app; scroll the host to the bottom (or clear it) for a clean read.
- G2 glasses on + connected via the Even app (Terminal Mode); R1 ring paired.
- Model `claude-opus-4-8`, `permissionMode: default` (unless the M3.1 spec says otherwise).
- **Permissions:** with `permissionMode: default`, **every tool — including Read/Bash — prompts**. Answer at the
  desk with the number keys (`[1]` allow, etc.) or tap the ring. A1/A4/A6 below use **tool-free** prompts on
  purpose so the viewport/markdown/thinking can be judged without permission noise.
- A throwaway dir / test files to edit (leave the git tree clean afterwards).
