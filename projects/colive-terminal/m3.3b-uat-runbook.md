## Walk

The picker is a **two-level menu**: type the command, then ↑/↓ to a value and **Tab** or **Enter** to apply.
**Esc** backs out of the picker (it does **not** interrupt the session). After a pick the status line shows
the active model/mode, e.g. `[idle · sonnet-4-6 · plan]`, and a transcript note `✓ model → Sonnet 4.6`.

| # | Do this (copy-paste / keystroke) | Pass = |
|---|---|---|
| E1 | Type `/model`, press **↓** to highlight **Sonnet 4.6**, press **Enter**. Then send: `which model are you? answer in one short sentence.` | Status line shows `· sonnet-4-6`; the note `✓ model → Sonnet 4.6` appears; the turn runs (reply is consistent with Sonnet) |
| E2 | Type `/mode`, **↓↓** to **Plan**, **Enter**. Then send: `add a one-line comment to the top of package.json` | Status shows `· plan`; Claude **plans only — does NOT edit the file** (proposes a plan / asks to proceed); package.json is unchanged |
| E3 | Type `/mode`, **↓** to **Accept-edits**, **Enter**. Then send: `add a trailing blank line to README.md` | Status shows `· acceptEdits`; the edit **applies with no permission prompt**; README.md gains the blank line |
| E4 | After E1's switch to Sonnet, toggle Wi-Fi **off ~5 s then on**; then send: `still sonnet? one word.` | Session **resumes on Sonnet** (status still `· sonnet-4-6`) — the self-heal reopen kept the chosen model, not the serve default |
| E5 | From the **glasses**, send any prompt while doing the above | Glasses send/receive unchanged (the control path is desk-only; events/SSE byte-compatible) |

> Picker sanity (optional): open `/model`, press **Esc** → the picker closes and the session is **not**
> interrupted (no "stopped"/error). Submitting a bare `/clear` resets the status line to the new session's
> defaults.

## Notes / known limitations (for the planner)

- **Status-line mode before any pick:** the desk seeds the *model* from the Hub (`/api/info`) but not the
  *mode* — so if `serve` is started with a non-default `--permission-mode`, the status line shows `· default`
  until you make a `/mode` pick. Cosmetic only (the Hub still enforces the real mode). Seeding the mode from
  the Hub was deferred to avoid touching the byte-compatible `/api/info` shape this rung → candidate for M3.3c.
- **Picker accept on Enter:** Enter accepts the highlighted value (spec §4 "Tab/Enter accepts"); **Esc** is the
  back-out gesture. (The spec's "bare submit = no-op note" clause is superseded by Esc-to-dismiss.)
